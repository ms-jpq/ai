# Intent

## Write it down

- Treat the user's request and relevant history as specification and evidence.

- Record the current direction.

  - Outcome.

  - Strategy.

  - Constraints.

  - Commitments.

  - Open questions.

- Keep it independent of plans and implementation.

## Stress test

- Separate observation from inference.

- Make contradictions and uncertainty visible.

- Compare plausible framings.

## Iterate

- Revise the model as direction changes.

- Treat the model as sufficient for now, not final.
